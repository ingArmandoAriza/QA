# # 🧪 QA Exploratory Testing – Bug Hunting

Ejercicio práctico de **Quality Assurance** enfocado en pruebas exploratorias sobre una aplicación web.

El objetivo fue explorar diferentes funcionalidades, identificar comportamientos inesperados y documentar los defectos encontrados de forma reproducible.

## 🔎 Pruebas realizadas

* Exploratory Testing
* Functional Testing
* Negative Testing
* Boundary Value Analysis
* UI & Visual Testing
* Navigation Testing
* Validation Testing

## 🐞 Resultados

Durante la sesión fueron identificados y documentados **12 bugs**, relacionados principalmente con:

* Validación de rangos y valores límite.
* Imágenes e íconos no visibles.
* Inconsistencias entre valores mostrados.
* Problemas de navegación.
* Reinicio de información o estado.
* Comportamientos inesperados de la interfaz.

Cada bug incluye:

* Título

* Resultado esperado
